A modern and fully responsive authentication system built with HTML, Tailwind CSS, and Vanilla JavaScript.

✨ Features
- 🔐 Secure Login & Registration
- 📧 Email Validation
- 🔑 Password Validation
- 👤 User Profile Management
- ✏️ Edit Profile
- 🗑️ Delete Account
- 👁️ Show / Hide Password
- 💾 Session Storage & Cookies
- 🌐 MockAPI Integration
- 🎨 Smooth UI Animations
- 📱 Fully Responsive Design

🛠️ Tech Stack
- HTML5
- Tailwind CSS
- JavaScript (ES6)
- MockAPI
- SessionStorage
- Cookies

Built with ZahraAzizi while learning modern frontend development.
